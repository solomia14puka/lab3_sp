# Лабораторна робота 3: Синтаксичний аналізатор (Flex + Bison)
**Виконала:** Пука Соломія, ТТП-31

## Опис проєкту
У рамках лабораторної роботи розроблено транслятор для підмножини мови C. Проєкт виконує лексичний та синтаксичний аналіз, будує абстрактне синтаксичне дерево (AST), обчислює математичні вирази (семантика) та генерує JSON для візуалізації дерева у веб-браузері.

**Файли проєкту:**
* `lexer.l` — лексичний аналізатор (Flex).
* `parser.y` — синтаксичний аналізатор та граматика (Bison).
* `ast.h` — структура вузла AST та функції обчислення/генерації JSON.
* `index.html` — веб-візуалізація дерева за допомогою D3.js.

## Інструкція з компіляції та запуску
Проєкт компілюється в середовищі Linux (Ubuntu/WSL). Необхідні пакети: `flex`, `bison`, `gcc`.

Збірка парсера та лексера:
   ```bash
   bison -d parser.y
   flex lexer.l
   gcc parser.tab.c lex.yy.c -o my_parser
